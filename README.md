GLOBAN è una rete di protezione pensata per i server FiveM RolePlay. 

Collegando il tuo server al sito tramite lo script GLOBAN, 
puoi bloccare l'accesso in rete le persone segnalate sul sito e contribuire a rendere più sicura l’esperienza di gioco per tutta la community. 

La piattaforma offre strumenti per gestire e monitorare i ban (solo ai proprietarei dei server), 
consultare i profili dei player e ricevere reclami, 
oltre a dare visibilità al tuo server tramite la pagina dei server protetti e il sistema di voti per i premi in game.

GLOBAN è la nuova piattaforme di protezione, più server sono connessi alla rete più vengono bloccati cheater/modder all'accesso alla rete.

Sè un server segnala cheater/modder non potranno più entrare nei server aderenti al sistema.

Per saperne di più collegati al sito: https://globan.link/
